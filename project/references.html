References

This page lists sources consulted while building the CIDOL Cycle Club project for WDD 131. It is intentionally left unstyled, per the course site-plan requirement.

Design and content references

  • Website Builder Expert, How to Choose Good Website Color Schemes — consulted for the site plan's color schema section.
  • Google Design, Choosing Web Fonts: A Beginner's Guide — consulted for the site plan's typography section.
  • MDN Web Docs, Window.localStorage — consulted for localStorage usage patterns in scripts/app.js.
  • MDN Web Docs, Using the Web Forms API — consulted for the membership form's native validation attributes.
  • W3C Web Accessibility Initiative (WAI), WCAG 2.2 Quick Reference — consulted for focus-visibility, color contrast, and form labeling.

Typography and iconography

  • Google Fonts — Fraunces, Work Sans, and JetBrains Mono typefaces, loaded via Google Fonts CDN.
  • All SVG illustrations, icons, and elevation-profile charts in this project were hand-built for this assignment and are original work.

Route and club data

Trail names, distances, and elevation figures are illustrative placeholders written for this course project and do not represent verified GPS survey data.
